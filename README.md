# RunWeather Bot

## Опис проєкту

**RunWeather Bot** — це Telegram-бот на Python, який отримує актуальні погодні дані для міста Кропивницький та надсилає користувачу повідомлення з інформацією про температуру, вітер, опади й рекомендаціями щодо одягу.
Проєкт допомагає швидко дізнатися про погодні умови та підготуватися до виходу на вулицю.

## Архітектурна схема

![Архітектурна схема RunWeather Bot](./architecture.png)

Схема демонструє послідовність взаємодії компонентів системи: Python-програма отримує погодні дані від Open-Meteo API, формує повідомлення та передає його користувачу через Telegram Bot API.

## Технологічний стек

- **Мова програмування:** Python 3.
- **Основна бібліотека:** `requests` — для виконання HTTP-запитів до API.
- **Погодний API:** Open-Meteo API — для отримання інформації про поточну погоду та ймовірність опадів.
- **Месенджер:** Telegram.
- **Інтеграція з Telegram:** Telegram Bot API — для надсилання погодних повідомлень.
- **Формат документації:** Markdown.
- **Середовище розробки:** Windows, Блокнот і командний рядок.

## Принцип роботи

1. Програма `main.py` надсилає запит до Open-Meteo API.
2. Отримані дані містять інформацію про температуру, швидкість вітру та опади.
3. Програма формує текстове повідомлення з погодними умовами та рекомендаціями.
4. Telegram Bot API надсилає повідомлення до вказаного чату.

## Налаштування

Для запуску проєкту необхідно встановити Python 3 та бібліотеку `requests`, створити Telegram-бота через BotFather і налаштувати змінні середовища `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`.

Запуск програми виконується командою:

```bash
python main.py
```
